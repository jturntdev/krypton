# Example: Acceptance Evidence

Weak proof:

```text
Tests passed.
```

Krypton proof:

```text
Focused tests passed.
The API returned the new payload with source labels.
The browser rendered that exact payload on the real route.
The old route returned a redirect and no longer appears as current documentation.
```

Tests prove important mechanics. Acceptance evidence proves the intended person
can see, use, inspect, or trust the changed result.
